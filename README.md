# По слогам

Веб-приложение для русских диктантов: микрофон телефона → локальный Vosk → локальная Qwen3-4B-Instruct-2507 Q4_K_M → локальный Piper ru_RU-irina-medium. Облачных API моделей нет. Телефон отправляет запись серверу по HTTPS. Скачивание моделей требует сети, дальнейший inference работает без внешних API.

## Windows 10/11 x64

Нужно минимум 8 ГБ RAM (лучше 16 ГБ) и около 8 ГБ свободного места. Интернет нужен при установке зависимостей и загрузке моделей; само распознавание, обработка текста и синтез работают локально. ngrok требует интернет постоянно.

1. Скачайте этот репозиторий через **Code → Download ZIP**, распакуйте архив в отдельную папку. Не запускайте файлы внутри ZIP.
2. Запустите `setup.bat` двойным щелчком. Он установит недостающие Python 3.12 x64, FFmpeg и Microsoft C++ Runtime через winget, создаст `.venv`, установит Python-пакеты и скачает три модели. Установка C++ Runtime может запросить права администратора. Если winget отсутствует, установите **App Installer / Установщик приложений** из Microsoft Store либо поставьте Python 3.12 x64, FFmpeg и Microsoft Visual C++ Runtime x64 вручную, затем повторите запуск.
3. Запустите `start.bat`. Дождитесь загрузки моделей: браузер откроется с готовым приложением. Локальная ссылка содержит отдельный код доступа. Окно запуска должно оставаться открытым; **Ctrl+C** останавливает сервер.

В PowerShell те же команды:

```powershell
.\setup.bat
.\start.bat
```

Если скачивание модели прервалось, повторите `setup.bat`: сохранённый `.part` будет продолжен. После установки новых системных программ иногда требуется закрыть и заново открыть терминал.

### Доступ с телефона через ngrok

Остановите обычный запуск и выполните:

```powershell
.\start.bat -Ngrok -NgrokUrl https://crawfish-earflap-wanted.ngrok-free.dev
```

Скрипт запросит **Agent Authtoken** в скрытом поле, поднимет сервер и туннель и выведет HTTPS-ссылку для телефона. Токен вводится на вашем компьютере и не включается в исходники. pyngrok может сохранить его в локальный `.ngrok.yml`, который исключён из Git. Не передавайте другим этот файл и ссылку с кодом доступа. На первом запуске бинарник ngrok скачивается автоматически в `bin/`. Домен должен принадлежать вашему аккаунту ngrok; можно передать собственный через `-NgrokUrl` или переменную `NGROK_URL`.

Откройте выведенную ссылку в Safari/Chrome и разрешите микрофон. Для автоматической озвучки во время записи нужны наушники. `http://IP-компьютера:8000` на телефоне не заменяет HTTPS: мобильный браузер обычно блокирует микрофон на таком адресе.

`start.bat -NoBrowser` отключает автоматическое открытие браузера. Для установки только библиотек, без многогигабайтных моделей: `setup.bat -SkipModels` (полный запуск приложения после этого требует обычного `setup.bat`).

Windows использует готовый CPU wheel `llama-cpp-python==0.3.19` для Python 3.12 x64; Linux — `0.3.36`. Компилятор C++ для Windows не нужен, требуется только Runtime. В `.github/workflows/windows.yml` подготовлена проверка установки на Windows без скачивания весов; она запускается после загрузки проекта в GitHub. Полный тест моделей описан ниже.

### Проверки на Windows

При запущенном `start.bat` откройте второй терминал в папке проекта:

```powershell
.\.venv\Scripts\python.exe check.py
.\.venv\Scripts\python.exe -m playwright install chromium
.\.venv\Scripts\python.exe browser_check.py
```

Первый тест проверяет локальные модели, фильтрацию, доступ к API и WAV. Второй проверяет мобильную вёрстку, запись тестового звука через браузерный микрофон и воспроизведение. Это автоматический тест с синтетическим звуком; работу с реальным микрофоном телефона проверьте по HTTPS-ссылке ngrok.

## Linux

При переносе на новый сервер выполните `bash setup.sh` (также нужен системный ffmpeg). Если загрузка весов прервалась, повторный запуск продолжит её.

## Запуск

Из этой папки: `.venv/bin/uvicorn app:app --host 0.0.0.0 --port 8000`.
В другом терминале: `.venv/bin/python tunnel.py` после добавления `NGROK_AUTHTOKEN` в секреты среды. Нужен **agent authtoken**, а не ngrok API key. Также можно использовать сохранённый конфиг `.ngrok.yml`. Домен задаётся через `NGROK_URL`; по умолчанию используется `https://crawfish-earflap-wanted.ngrok-free.dev`. Скрипт выводит ссылку для телефона с кодом доступа в URL fragment. Не публикуйте её. API требует этот код; он хранится в `.access-token`. Код сохраняется между запусками; для замены задайте `APP_TOKEN` или удалите `.access-token` перед запуском.

Открыть ссылку в Safari/Chrome, разрешить микрофон, записать фразу, нажать кнопку повторно. Запись автоматически заканчивается через 60 секунд. Речь можно исправить вручную. «Разобрать по слогам» запускает LLM, кнопка у слова или «Всё» — локальный синтез. «По буквам» помогает услышать точное написание. Есть непрерывный режим: отдельные записи по 12 секунд поступают в очередь обработки. Результаты фрагментов добавляются в общий список, автоматическая озвучка идёт по очереди. На границах фрагментов слова могут обрываться; для точного распознавания лучше запись отдельных фраз. При переполнении очереди запись останавливается с сообщением. Для автоматической озвучки используйте наушники, иначе микрофон услышит голос приложения. На телефоне держите страницу открытой.

## Проверки и ограничения

` .venv/bin/python check.py` — загрузка моделей, авторизация, фильтрация, WAV и распознавание. `.venv/bin/python browser_check.py` — мобильная вёрстка и обработка слова.

Аудио временно декодируется ffmpeg и удаляется после запроса; история диктантов не сохраняется на сервере. Текст остаётся на странице до её закрытия. Типовые замечания удаляются правилами, остальные фильтрует Qwen3. Цитаты с командами могут удаляться ошибочно; при необходимости выключите фильтр. Для слогов используется ограниченная генерация с правилами русского слогоделения: модель не может менять буквы слова. Эти правила не заменяют морфологический словарь. LLM не является словарём: фильтрация, слоги и распознавание могут ошибаться. Проверка запрещает модели добавлять слова, отсутствующие в исходном тексте, но не доказывает правильность фильтрации или слогоделения. Учительские замечания внутри диктуемого текста иногда невозможно отличить без контекста. На шумной записи качество Vosk снижается. Работает один запрос к моделям за раз. Ngrok — временный туннель, доступный пока запущены среда и процессы; для постоянной работы нужен постоянный сервер.

Модели: https://alphacephei.com/vosk/models (small-ru-0.22); https://huggingface.co/unsloth/Qwen3-4B-Instruct-2507-GGUF; https://huggingface.co/rhasspy/piper-voices/tree/main/ru/ru_RU/irina/medium (лицензия голоса — MODEL_CARD в репозитории).

В управляемой облачной среде ngrok требует исходящего TCP к `connect.ngrok-agent.com:443`. Обычный HTTP-прокси, разбирающий HTTP после TLS, может закрывать служебный протокол ngrok с `session closed`. В таком случае разрешите адрес в настройках TCP сети среды и используйте её штатный TCP-прокси. Настройка `root_cas: host` позволяет доверять сертификатам среды без отключения проверки TLS.
